## 🔍 TROUBLESHOOTING

### **❌ If Map Doesn't Load:**
1. **Check Console**: F12 → Console for errors
2. **Network Tab**: Verify Leaflet CSS and JS load
3. **Clear Cache**: Hard refresh (Ctrl+F5)
4. **Try Different Browser**: Chrome, Firefox, Safari

### **❌ If Markers Don't Show:**
1. **Wait for Load**: Map initialization takes 2-3 seconds
2. **Check Network**: Ensure OpenStreetMap tiles load
3. **Zoom Out**: Use mouse wheel or zoom controls
4. **Refresh Page**: Click refresh button if error shown

### **❌ If Route Doesn't Display:**
1. **Enter Valid Locations**: Use Vietnamese location names
2. **Wait for Calculation**: Route calculation takes 1-2 seconds
3. **Check Suggestions**: Use dropdown suggestions
4. **Try Different Route**: Test with other location pairs
